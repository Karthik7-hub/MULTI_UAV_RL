## 1. Executive Summary

A critical audit of the publication figure generation suite was conducted following discovery of static, hardcoded dictionaries in `plots/render_publication_figures.py`. The investigation verified that:

1. **Hardcoded Metrics Defect**: The function `export_algorithm_metrics_csv()` loaded `results/metropolis_trajectory_records.csv` into variable `df`, but completely discarded `df` and wrote a static, hardcoded dictionary list (`metrics_rows`) to disk.
2. **Unsupported Success Claims in Figure A**: The fleet status summary box in Figure A asserted `"Status: Success (100%)"` and `"Fleet Interventions: 12 (0 Collisions)"` via static text template strings rather than deriving arrival status from UAV proximity to mission stations ($d \le 5.0\text{ m}$).
3. **Misleading Controller Labels**: Trajectories in Figures A and B were labeled `"Hierarchical A* + MAPPO (Proposed)"`, implying that the MAPPO neural network steered the physical aircraft. In reality, the evaluated script ran with `residual_weight = 0.0`, meaning 100% of spatial displacement was generated by **3D A* Waypoint Pure Pursuit Tracking**, with MAPPO controlling only task offloading.
4. **APF Parameter Fabrication in Figure C**: Figure C claimed to depict the potential field formulation "Directly from `models/apf.py`" using parameters $k_{\text{att}}=0.8, k_{\text{rep}}=1500.0, d_0=22.0\text{ m}$. In reality, `models/apf.py` implements $k_{\text{att}}=1.0, k_{\text{rep}}=80.0, d_0=25.0\text{ m}$, an effective margin of $6.0\text{ m}$, and a tangential circulation field $k_{\text{tangent}}=45.0$ which breaks local saddle deadlocks.
5. **Single-Seed vs. Multi-Seed Evidence Confusion**: Single-seed trajectory illustrations (Seed 101) were titled and formatted as though they represented general benchmark performance.

**Remediation Action**: All hardcoded placeholder tables and assertions were removed. All metrics are now calculated on-the-fly directly from raw 10 Hz physical trajectory records. Controller descriptions have been corrected to state the true underlying motion controllers. Cryptographic hashes of all historical and updated artifacts have been recorded, and a dedicated automated test suite (`tests/test_scientific_integrity.py`) has been added to guarantee that reported figures and tables never diverge from raw experimental data.
