# MULTI_UAV_RL Artifact Manifest & Provenance Specification

## 1. Overview & Provenance Standards
To maintain scientific reproducibility and integrity, this manifest catalogs all tracked source modules, reproducible runtime fixtures, generated evaluation artifacts, and optional neural network checkpoints.

Under the refactored research integrity standards:
- **No synthetic confidence intervals or hardcoded metrics:** All benchmark tables, CSV logs, and publication plots must be derived from actual forward-pass simulation records.
- **Fail-closed checkpoint validation:** Neural policy evaluators reject missing, corrupted, or incompatible weights. Untrained random weights can never enter benchmark evaluations unnoticed.
- **Clean checkout independence:** Core test suites and deterministic smoke tests must execute out of the box without relying on gitignored scratch scripts or pre-computed historical runs.

## 4. Model Checkpoint Specifications

When trained checkpoints are saved or transferred, their compatibility is governed by the following architectural signatures:

- **MAPPO Pure / Residual:**
  - Local Observation: 22 dimensions (UAV kinematic state, target direction, 3 peer offsets, task queue, closest obstacle)
  - Centralized Critic State: 52 dimensions ($4 \times 13$, including 3D relative goal vectors)
  - Offload Action Space: Categorical(5) (0=Local, 1..3=Peers, 4=Ground Edge)
  - Movement Action Space: Normal(3) continuous displacement $(\Delta x, \Delta y, \Delta z) \in [-15.0, 15.0]$ m
- **CPPO:**
  - Joint Observation / State: 52 dimensions
  - Obsolete checkpoints with 40-dim states lacking 3D relative goal direction are explicitly rejected with `RuntimeError`.
